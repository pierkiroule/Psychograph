# Morphoz •° — Le psychographe

Importe tes souvenirs. Révèle ton rêve.

```sh
npm install
npm run dev
npm run build
```

PWA hors ligne après premier chargement de la version de production. Export en temps réel. Tester WebGL et MediaRecorder sur Android.
